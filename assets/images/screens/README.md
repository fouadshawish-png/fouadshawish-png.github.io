# Screenshots

ضع صور لقطات التطبيق هنا.

## أسماء الملفات المعتمدة
- `screen-1.webp` (مفضل)
- `screen-2.webp` (مفضل)
- `screen-3.webp` (مفضل)

أو بديلًا:
- `screen-1.png`
- `screen-2.png`
- `screen-3.png`

الصفحة الرئيسية تستخدم WebP/PNG إن وُجدت، وإلا ستعرض ملفات SVG placeholder الموجودة:
- `screen-1.svg`
- `screen-2.svg`
- `screen-3.svg`

## مقاس مقترح
- عرض: 1080px
- ارتفاع: 2400px (أو أي ارتفاع مناسب)
- أو استخدم لقطات أفقية إذا كانت واجهات التطبيق أفقية.

ملاحظة: سيتم عرض الصور داخل مربعات بارتفاع ثابت، لذا يُفضّل صور واضحة (PNG أو JPG).
